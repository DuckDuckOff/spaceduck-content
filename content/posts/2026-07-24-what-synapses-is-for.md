# What SynapSes Is For

SynapSes is a directory-based node system for turning opportunities into local, living instances.

The idea is simple: each server owns its own SynapSes system. An instance is not copied everywhere or treated as a static package; it emerges when the system recognizes an opportunity worth taking forward.

Each local system has clear spaces for its work:

- `origin/` for where a signal begins
- `opportunities/` for possibilities being considered
- `instances/` for things that have emerged
- `channels/` for communication paths
- `lineage/` for the history of how things came to be

SynapSes is meant to give a server a boundary, a memory, and a way to develop structure around meaningful opportunities. The first implementation establishes that local system boundary. Inquiry, capability compilation, validation, and sealing are still separate lifecycle operations to be built.

In that sense, SynapSes is infrastructure for emergence: a place where a possibility can be noticed, shaped, validated, and eventually become its own node.
